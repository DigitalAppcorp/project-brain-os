# Project Brain OS — New Project Starter

## Initial instruction

Activate Project Brain OS from `DigitalAppcorp/project-brain-os`.

The user is the Product Owner. Before coding:

1. audit the real repository/files/backend;
2. create project-specific `AGENTS.md`;
3. create `docs/MASTER_ROADMAP.md`;
4. capture product vision without treating it as executable scope;
5. classify modules U/N/A/M/I;
6. separate Validation Lane and Implementation Lane;
7. open an Idea Bank before closing major product concepts;
8. decide whether each candidate needs:
   - cheap experiment;
   - minimum useful real core;
   - immediate implementation because it is required infrastructure/utility;
9. close product specification before technical architecture;
10. close architecture before implementation;
11. preserve prior contracts and behavior;
12. use Git branches, tests, security review and durable handoff.

Do not copy Project Brain OS into the product repository. Store only product-specific rules/state there and optionally record the Project Brain OS version in use.
