# Pattern — Idea Bank + Conceptual Audit

## Input
The Product Owner may provide ideas in any order and without technical structure.

## AI audit for each idea
- user problem/desire;
- recurring utility;
- engagement/retention;
- acquisition potential;
- monetization potential;
- dependencies;
- technical/operational cost;
- security/privacy/moderation;
- network/cold-start risk;
- overlap with existing capabilities;
- simpler alternative;
- MVP fit.

## Output classification
CORE / MVP REDUCED / ENGAGEMENT / IDENTITY-STATUS / ACQUISITION / MONETIZATION / INFRASTRUCTURE / FUTURE / POSTPONE / DISCARD.

Classification does not authorize implementation.
