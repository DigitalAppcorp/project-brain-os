# Pattern — Git Workflow

1. audit current main;
2. create one coherent branch;
3. commit durable docs/architecture with the work;
4. keep migrations versioned;
5. inspect diff;
6. build/test;
7. create/update PR;
8. merge only after required product/backend checks;
9. verify main;
10. update roadmap and handoff.

Code in a branch is not “completed”.
