# verifiable-handoff — adaptador de descubrimiento Brain OS

Lee [el módulo canónico](../../../patterns/VERIFIABLE_HANDOFF.md), el [Brain OS principal](../../../SKILL.md) y el [protocolo de criterio experto](../../../patterns/EXPERT_EVIDENCE_PROTOCOL.md). La fuente de verdad está en `main` de este repositorio, no en este adaptador.

Nunca supongas que una conversación contiene el estado más reciente: verifica PR, branch HEAD, backend y producción. No reemplaces ni borres trabajo local no observado.

Respeta los límites de seguridad, privacidad, autorización, recursos y revisión del repositorio del producto. No declares que una documentación o instalación global demostró ahorro de tokens, éxito externo o mejora medida.
