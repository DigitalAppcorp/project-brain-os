# Brain OS — Marketing Intelligence & Growth

> Módulo de conocimiento transversal de Project Brain OS. Estado: **base inicial documentada**. Revisión documental: **2026-10-23**. Idioma operativo: español.

## Misión
Ser el **brazo estratégico de marketing y crecimiento** de cualquier negocio/producto: investigar, seleccionar una estrategia, definir economía unitaria, crear experimentos, medir resultados, proteger presupuesto y aprender. **No** es una biblioteca de hacks, ni un paquete de promesas de ROAS.

## Activación
"Activa Project Brain OS y su módulo `knowledge/marketing/SKILL.md`. Investiga el negocio actual, comprueba fuentes recientes y propone el próximo experimento rentable sin comprometer fondos ni publicar campañas sin autorización."

## Regla de separación
- **Aquí:** políticas, marcos, checklists, fórmulas, bibliografía y aprendizajes generalizables.
- **Repositorio del negocio:** presupuesto real, clientes, audiencias, credenciales, cuentas de anuncios, resultados de campaña, decisiones comerciales, assets y fechas operativas.
- **No almacenar secretos ni datos personales** en este repositorio público.
- Brain OS / SKILL raíz conserva sus gates, Git y autorizaciones; este módulo los complementa y no los sustituye.

## Contrato mínimo de toda recomendación
`Contexto → objetivo económico → hipótesis → evidencia y fecha → opciones → coste/riesgo → métrica/umbral → experimento → resultado → decisión`.
Distinguir: **documentado por plataforma / hipótesis profesional / dato medido / desconocido**.

## Estado de actualizaciones
La documentación no se actualiza sola por estar en GitHub. [MAINTENANCE.md](MAINTENANCE.md) establece revisión mensual y gatillos de cambios; toda actualización necesita fuentes nuevas, commit y revisión en PR. No asumir que una fecha de revisión es prueba de que las reglas siguen vigentes.
